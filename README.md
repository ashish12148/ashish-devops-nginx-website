## ⚙️ Deployment Process

1. Created IAM User and Group.
2. Launched an EC2 instance.
3. Configured Security Group.
4. Connected to EC2 using SSH.
5. Installed Nginx Web Server.
6. Created a custom HTML and CSS website.
7. Deployed the website on AWS EC2.
8. Uploaded project files to GitHub.
